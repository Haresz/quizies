# 🎯 Quizies: Interactive Quiz Platform

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Project-blue?style=for-the-badge)](https://quizies.vercel.app/)

**Quizies** is a dynamic and interactive web-based quiz application designed to test users' knowledge through an engaging user interface. Built with a focus on seamless interactions and immediate feedback, this platform provides a smooth testing experience from the first question to the final score calculation.

For a Frontend Developer, building a quiz application is a rigorous test of **client-side state management**. This project demonstrates my ability to handle complex application states—such as tracking user answers, calculating scores in real-time, managing component transitions, and conditionally rendering user interfaces based on active gameplay.

## ✨ Core Features

*   **Dynamic Question Rendering:** Seamlessly transitions between questions without full page reloads, ensuring a fast and fluid user experience.
*   **Real-time Score Tracking & State Management:** Accurately captures user inputs, validates answers, and maintains the score state throughout the quiz session.
*   **Immediate Visual Feedback:** Provides clear, instant feedback on correct and incorrect selections.
*   **Result Summary Dashboard:** Calculates and displays a comprehensive final score and performance summary upon completion.
*   **Engaging UI/UX:** Features a clean, minimalist design with subtle "3D flat" interactive elements (like tactile buttons) that reduce cognitive load and keep the user focused on the content.

## 🛠️ Tech Stack & Architecture

## 🚀 Local Development

To run Quizies locally on your machine:

1.  **Clone the repository:**
```bash
    git clone [https://github.com/Haresz/quizies.git](https://github.com/Haresz/quizies.git)
    cd quizies
```

2.  **Install dependencies:**
```bash
    npm install
    # or yarn install / pnpm install
```

3.  **Run the development server:**
```bash
    npm run dev
    # or yarn dev / pnpm dev
```

4.  Open your browser and navigate to the local server URL provided in your terminal (typically `http://localhost:5173` or `http://localhost:3000`).
